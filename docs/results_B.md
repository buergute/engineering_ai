# B · 预测方法和评测设置

Kelmarsh 模型按起报时刻读取本机与邻机功率、风速，使用滞后值、过去一小时的均值和时间特征。质量感知模型还使用近期缺测计数、连续缺测或冻结长度、可用邻机数。后备模型移除本机风速及其质量特征。特征来自扰动后的输入，三个时距的目标均来自同一机组未扰动的原始功率。

训练只使用 2019–2020 年，使用 2021 年早停，使用 2022 年校准。各段单独生成样本与目标，时距为 10、30、60 分钟。LightGBM 采用仓库已有超参数。B 的本轮开发固定同一组超参数，没有按场景调参。模型的三个分位数为 0.1、0.5、0.9。区间裁剪到物理边界，并保留中位数。

持续性取本机最近有效功率，区间半宽取校准段绝对残差分位数。统一补值模型使用前向填充和单组 CQR。质量感知模型按干净与退化组校准。路由评测在本机风速连续冻结或连续缺测时切换后备模型；表 1 衡量该预测策略，智能体使用其他证据的决策另见表 3。

每个场景和时距共用机组、起报时刻和原始目标。持续性没有历史有效功率的起报点从全部方法中同时剔除。随机种子、样本上限、bootstrap 次数、风速分层边界见 `configs/forecast.yaml`。按起报日整块有放回重采样，同一天的全部入样机组与方法共用权重；每次重采样后重新计算相对持续性提升。比值分母为零时指标缺失。覆盖率为原始观测落入闭区间的频率。

H1 采用预先固定的描述性标准：同场景、同时距下，质量感知的 MAE 严格小于补值模型且覆盖率至少持平；三个时距都满足才判该场景成立。去掉质量特征时保留原输入缺失值与原分组规则；去掉分组校准时固定模型预测，只把校准量改为全组估计。低、中、高风速按起报时刻未扰动的本机风速划分，缺测另列。
