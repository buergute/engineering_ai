# B · 真实数据重跑清单

1. 对照字段字典、原始文件校验和、各年各机有效率。核验区间开始转区间结束只执行一次，宽表时间有序、唯一、10 分钟等距，缺失编码转 NaN，功率 kW 转 MW，风速单位 m/s，额定 2.05 MW。确认数据集与配置切分，记录提交号和依赖版本。
2. 运行 `pytest -q`。开发验证运行 `python -m eval.forecast_validation`，从真实宽表只读到 calib 结束。此命令覆盖 `outputs/forecast_validation/` 下的开发模型、指标和报告。缺少配套 meta 时使用与 A 预处理脚本相同的邻机表和容量，见 `configs/forecast.yaml`。
3. 全组冻结前备份原产物。准备配套 scada.parquet、events.csv、meta.json 并确认事件可见性。运行 `python -m models.train` 同批重建 `artifacts/reference.json`、`artifacts/models.pkl`。A 的 `python -m eval.thresholds` 独立更新 `artifacts/thresholds.json`，其无真值的真实数据路径需由 A 核验。
4. A 的基线已使用 2023 测试段。归档 A 当时的模型和已有输出，补记该结果是否影响后续选型。组内确定需要同段复评后执行 `python -m eval.numeric`，写入 `outputs/numeric_results.md`、`forecast_metrics.csv`、`wind_coverage.csv`（均位于 outputs）。核对数据集、模型版本、样本天数、各时距误差、覆盖率、宽度和 H1。归档配置、模型与全部结果后撰写报告。

复查结果时使用 `python -m eval.numeric --render-only`（开发验证加 `--split val`），从已保存的 CSV 和 forecast_run.json 重排表格。split_mae.csv 用于检查不同年份的误差差距；风资源和运行工况的跨年变化也会影响差距。
