# 真实数据重跑清单

此清单以 A 交付真实数据读取、扰动实现且完成数据验收为前提。当前仓库的切分时间仍是占位值，不能把占位切分上的结果作为真实评测。

1. 记录数据版本、下载日期、许可证、校验和、机组及时间范围；确认每年及各机组的有效率、缺失值编码、风速单位（m/s）、功率单位（MW）、额定功率（2.05 MW）和时间戳表示区间开始还是结束。核实时间对齐及重复记录，记录负功率和停机样本的处理方式。
2. A 更新并确认 `configs/split.yaml` 和字段字典，核查预测目标窗口不跨切分边界；功率曲线、邻机比例和补值参数仅在 train 拟合。验证输入扰动不会更改原始预测目标。
3. 固定配置与随机种子，在开发阶段运行 `pytest`、`python -m models.train`、`python -m eval.thresholds`。训练使用 train，早停及阈值选择使用 val，区间校准使用 calib。记录模型、配置及数据版本。上述训练和阈值模块目前尚不存在，具体产物路径应在实现后补齐。
4. 冻结模型、校准、评测方案后，最终运行一次 `python -m eval.numeric`。该模块目前尚不存在；实现后应明确列出会覆盖的模型、阈值及 `outputs/` 产物，并在运行前备份已有结果。报告只使用真实测试段脚本产物，核对各场景、时距及风速分组样本数与覆盖率。
5. 如加入新字段，先登记字段字典并验证可用时间；后备模型不得依赖本机风速及其相关字段。区间覆盖率是测试段实测值，不作理论保证。
