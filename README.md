# 风电功率异常检测与可信预测智能体

先找出可疑的数据点，用字段证据逐个复核其属于数据问题、运行状态变化、风况变化还是无法解释，再据此给出带可信区间的功率预测。找不到证据就如实报告，不通过排除法给出原因；不做偏航偏差、叶片结冰或齿轮箱故障等细粒度根因归因。

## 流程与分工

```text
① 理解请求（C）→ ② 读数据（A）→ ③ 检测与复核（A）
    → ④ 决策（C）→ ⑤ 预测（B）→ ⑥ 校验与输出（C）
```

② 读取本机及邻机过去 7 小时的功率、风速和状态字段并生成快照哈希。④ 选择模型、剔除邻机、选择校准分组和决定是否提示人工核查。⑤ 输出 10、30、60 分钟中位数及 80% 区间；⑥ 校验通过后输出报告。

③ 按顺序采用第一个有正面证据的类别：

| 类别 | 判定证据 |
| --- | --- |
| 数据问题 | 冻结、风速计矛盾、越界、缺测或漂移 |
| 运行状态变化 | 停机或限电事件（含刚结束）、转速接近零，或额定风速以下桨距角偏大 |
| 风况变化 | 功率沿曲线随风速变化，且邻机同步或本机风速标准差高于同风速正常水平 |
| 无法解释 | 以上均无正面证据，建议人工核查 |

报告标签为正常、数据变差（已调整预测）、运行状态变化、无法解释、需要补充信息、无法完成。大模型仅可用于理解请求和组织语言；规则解析器可独立运行。

## 运行

安装 `requirements.txt` 后，运行 `bash scripts/run_all.sh`：依次测试、生成合成数据、训练、验证段阈值、预测评测、复核评测和智能体题目。产物写入 `data/synth/`、`artifacts/` 和 `outputs/`，重复运行可能覆盖。单独运行：

| 产物 | 命令 | 负责人 |
| --- | --- | --- |
| 表 1：预测，H1 | `python -m eval.numeric` | B |
| 表 2：检测与复核，H2 | `python -m eval.review_eval --n 40` | A |
| 表 3 底稿：智能体，H3 | `python -m agent_eval.run_tasks` | C |

表 3 应包含固定流程和去掉校验的对照。题库规划共 26 题：正常 2、风况变化 4、缺字段 4、数据质量 6、运行状态 3、无法解释 2、工具故障 3、未来信息诱导 2。

## 数据与切分

数据源为 Kelmarsh SCADA。规划 train 2019–2020、val 2021、calib 2022、test 2023，段间留一天；真实数据接入后 A 须核对各年有效率再定稿。训练参数只用 train 拟合，val 用于早停和阈值选择，calib 用于区间校准，test 只用于最终评测。目标来自未扰动的原始数据。

## 仓库与职责

| 路径 | 内容及负责人 |
| --- | --- |
| `common/`, `configs/` | 公共格式、数据访问和切分；A 维护切分 |
| `tools/`（含 `review_context.py`）、`perturb/`、`tasks/` | 数据读取、检测复核、扰动和题库；A |
| `eval/thresholds.py`、`eval/review_eval.py` | 欠发与复核阈值、表 2；A |
| `models/`、`eval/numeric.py`、`eval/metrics.py` | 特征、预测、指标和表 1；B |
| `agent/`、`agent_eval/`、`ui/` | 决策、校验、报告和表 3；C |
| `docs/`、`tests/` | 接口和数据说明、测试；全组 |

不读取起报时刻后的信息；报告数字必须来自工具输出；查不到就如实说明。接口变更需同步文档和测试。合并前运行测试，不提交数据、模型或输出。

## 待办与已知局限

真实数据字段、时间约定和各年有效率待 A 核验；现有合成实验不能代替真实评测。事后补录的限电在高风速下可能缺乏足够证据而被判为无法解释。复核规则、缺字段降级和多种子题库仍需逐项验证。

多种子题库检查发现事后补录限电的桨距证据并非每次都满足判定条件；事件查询故障题在字段仍提供运行状态证据时也可能与题目预期不一致。风况事件挑选已改为遍历机组，但仍需重新完成全部种子的验证。
